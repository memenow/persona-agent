Documentation

In-depth documentation for the Persona Agent project. The top-level README.md is the quick-start entry point; this directory documents the details that don’t fit there.

Contents

File Use it for

Conventions

  • Examples assume the server is reachable at http://127.0.0.1:8000 (the default bind). Adjust the host/port for your environment.
  • JSON bodies are shown as pretty-printed. The server accepts compact JSON as well.
  • Environment variables follow the prefix API_* for server runtime, OPENAI_* for LLM client, PERSONAS_DIR/LLM_CONFIG_PATH/MCP_CONFIG_PATH for file locations.
